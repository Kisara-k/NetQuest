# Product Requirements Document (PRD) — NetQuest: Protocol Architect

## 1. Product Vision & Objectives

**NetQuest: Protocol Architect** transforms the 14 computer networking lectures in [`Lectures.json`](../Lectures.json) into a fluid, tactile, single-user interactive game and protocol simulation suite.

### Primary Goals
1. **Deep Conceptual Understanding ("Understand"):** Replace walls of raw, unformatted slide text with structured visual mental models, protocol header diagrams, side-by-side comparison tables, cleaned searchable source slides, and interactive simulations where learners manipulate real networking parameters.
2. **Long-Term Retention ("Remember"):** Combine gamified **Lecture Boss Quizzes** (active recall + packet debugging scenarios) with an **SM-2 Spaced Repetition Memory Vault** and a timed **Exam Blitz Mode** so facts, formulas, header fields, and architectural trade-offs stick permanently.
3. **Zero-Friction Personal Use:** Run locally with a single command (`pnpm dev`) inside `app/`, requiring no login walls, no external databases, and no backend microservice complexity.

### FR-02: Stage 1 — Concept Briefing & Cleaned Source Slide Inspector (`/lecture/[id]`)
- **Concept Briefing Tab:**
  - Displays 4–6 structured, scannable **Concept Cards** per lecture, each with a visual badge, concise explanation, key bullet points, and a **"Mental Model / Exam Tip"** callout.
  - Renders structured **Protocol Comparison Tables** or **Header Field Maps** where applicable.
- **Source Slide Inspector Tab (`Lectures.json` Viewer):**
  - Displays the cleaned, de-duplicated text from [`Lectures.json`](../Lectures.json) formatted into readable slide sections.
  - Provides an instant keyword search/filter bar that highlights matching networking terms inside the lecture text.

### FR-03: Stage 2 — Interactive Protocol Lab (`/lecture/[id]?tab=lab`)
- Loads the lecture's dedicated interactive simulation powered by one of the 4 reusable engines (`HeaderAssembler`, `SequenceSimulator`, `TopologyLab`, `MatrixArena`).
- Includes clear mission instructions, interactive controls, real-time validation feedback (explaining *why* a frame/header/step is valid or invalid), a **"Hint / Protocol Spec"** drawer, and a **"Reset Lab"** button.
- Completing the lab awards **+150 XP** (first completion) and marks the lecture's **Protocol Lab Badge** as complete.

### FR-04: Stage 3 — Lecture Boss Battle Quiz (`/lecture/[id]?tab=quiz`)
- Presents 5–8 high-yield active recall and scenario-debugging questions covering the lecture's key concepts, formulas, and edge cases.
- Supports keyboard selection (`1`–`4` keys and `Enter` for Next Question).
- Tracks a live **Combo Streak Multiplier** (`1x`, `1.5x`, `2x`) and awards XP per correct answer.
- Immediately after each answer, displays a rich **Protocol Diagnostic Explanation** citing the exact concept from `Lectures.json`.
- Any missed question automatically flags the corresponding concept flashcards in the **SM-2 Memory Vault** for priority review.

### FR-05: Global Packet Journey Sandbox (`/sandbox`)
- Standalone interactive 3-column simulator:
  - **Left Column:** Interactive 7-Layer OSI / 5-Layer TCP-IP Stack Explorer.
  - **Center Canvas:** Animated network topology (`Sender Host` → `L2 Ethernet Switch` → `L3 NAT/Firewall Router` → `WAN ATM/MPLS Core` → `Target Web/TLS Server`) with Play/Pause, Step Forward, Step Back, and Speed (`0.5x`, `1x`, `2x`) controls.
  - **Right Column:** Live **PDU Byte/Field Inspector** showing the exact headers wrapped around the payload at the current simulation step (`HTTP/TLS` → `TCP Segment` → `IPv4/IPv6 Packet` → `802.3/802.1Q Ethernet Frame` → `Physical Bits`), plus 3 selectable **Scenario Presets**:
    1. *HTTPS Web Request over NAT & VLAN (`TCP` + `IPv4` + `802.1Q` + `TLS`)*
    2. *IPv6 Native SLAAC & End-to-End Flow (`ICMPv6 133/134` + `IPv6 EUI-64`)*
    3. *Site-to-Site IPsec VPN Tunnel (`ESP Protocol 50 Tunnel Mode`)*

### FR-06: SM-2 Spaced Repetition Memory Vault (`/vault`)
- Houses **90+ curated technical flashcards** spanning all 14 lectures (6–8 cards per lecture).
- Implements the **SM-2 Spaced Repetition Algorithm** with 4 self-grading buttons after flipping a card (`Space` bar):
  - `1` — **Again** (Reset interval to 1 day / immediate re-queue, reduce ease factor)
  - `2` — **Hard** (Short interval multiplier `1.2x`)
  - `3` — **Good** (Standard SM-2 interval progression)
  - `4` — **Easy** (Bonus interval multiplier + ease factor boost)
- Allows filtering by **"Due Now"**, **"All Cards"**, **"Flagged / Missed in Quiz"**, or by specific **Sector / Lecture**.

### FR-07: Exam Blitz Arcade Mode (`/blitz`)
- A fast-paced cross-lecture challenge mode with two selectable presets:
  - **60-Second Speed Blitz:** Answer as many randomized questions across all 14 lectures as possible in 60 seconds.
  - **20-Question Final Exam Simulation:** Untimed 20-question comprehensive exam sampled evenly across all 5 Sectors with a final grade breakdown by lecture showing weak spots to review.

### FR-08: Local-First Persistence & Backup
- Automatically saves all XP, badges, lecture completion states, quiz high scores, and SM-2 card schedules to `localStorage` and syncs to `app/.data/progress.json` via `/api/progress`.
- Provides a **Settings / Data Modal** in the top bar with **Export Progress JSON**, **Import Progress JSON**, and **Reset Progress (with confirmation)**.

## 5. Non-Functional Requirements

- **Performance:** Instant page transitions (<100ms) and smooth 60fps animations using React 19 / Next.js App Router and `motion/react`.
- **Offline & Zero-Dependency Reliability:** No external API keys, no remote database connections, and no external audio/image assets required at runtime.
- **Accessibility & Keyboard First:** Full keyboard shortcuts for flashcards (`Space`, `1`–`4`) and quizzes (`1`–`4`, `Enter`), high-contrast text ratios (`≥ 4.5:1`), and clear visual indicators alongside color coding.
